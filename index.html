Format only ever moves whitespace and re-cases keywords — string literals, quoted identifiers and comments come through byte for byte. After every run the tool re-tokenises its own output and compares the token stream against the input's, and the Token Check tile reads match only when nothing was lost or invented. Minify is the one exception: a -- comment would swallow the rest of a one-line query, so it is rewritten as a block comment. Subqueries get their own indented block; ordinary function-call parentheses stay on one line.
